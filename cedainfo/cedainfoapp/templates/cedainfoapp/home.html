CEDAinfoDB

The CEDAinfoDB contains various internal data related to the administration of datasets and services. The interface uses both customised database views and the Django admin interface. The admin interface can be accessed using the link below, or using the Home link on the bar above.

These should probably be moved to the 'Services -decommissioned collection, but make sure that the document is not referenced by another service record first
